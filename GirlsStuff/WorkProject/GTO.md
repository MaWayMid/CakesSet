# 原神是悼明之作
原神，其实是悼明制作。唉，你先别急着喷我，你先别急着反驳我，你先听听我的观点，听听我的论述，然后再做出一个综合客观，合理的评判。总之，你先别急，我这可不是什么乐子人提出的娱乐理论。（憋笑）  
>提瓦特过去有过权力更替，远古由执掌七种元素的七位“龙王”统治，后来陆续有来自世界之外的“降临者”来到提瓦特，前两位降临者被称为“第一王座”和“第二王座”。“第一王座”即为“天理”，祂打败了七龙王，将他们的“古龙大权”夺走，分派给了“尘世七执政”，这些权能后来被称为“神座”。幸存的七龙王，有些存世，有些转生。  

我们先来看第一段话，这是对中国古代政治历史的深刻隐喻。先是远古执掌提瓦特大陆的七位龙王，为什么要特地强调一个远古呢？因为是很久以前发生的事情了。这不废话吗？（摆手）而且是七位龙王。什么意思？什么意思？什么意思？为什么呢？仔细想想。上古时代的七位龙王，龙自古以来就是中原部落的精神图腾，龙在华夏文化中代表着正统天命，七位龙王寓意着七个代表着华夏中原正统的国家，同时存在，相互独立，互不归属，这其实暗喻着战国时代的七个宗法制国家。远古时代的七位龙王，其实就是就是指代着远古时代，由周王朝分封建立起来的礼乐宗法秩序。七龙王有七位，那有的朋友就会说啦，那你说秦朝它算不算？当然，秦朝不算，也算。为什么？因为我们都知道，在商鞅变法后，秦朝已经从一个宗法制国家变为了封建制国家。七个分封国家，被“降临者”打败，然后被分配给了“尘世七执政”，这段话就是在暗喻着宗法制被封建制的时代浪潮所打败，时代的车轮滚滚前进，碾压着每一位落后的宗法王侯嘛。那么秦，是第一个被战胜的，而且是被自己战胜的。而我们再看“幸存的七龙王，有些存世，有些转生”这句话，信息量很大。幸存的七龙王，这句话有两个含义，第一个含义是，我们先前就知道七龙王是宗法制的象征，那么宗法制，它被封建制给打败了，但是它并没有就此泯灭，它依然存在于世上。为什么？项羽刘邦等人灭掉秦朝之后，西楚霸王，它又开始分封诸侯了。那再往后看，刘邦建立汉朝以后，建立的是什么？郡县制的汉朝？对了，对了一半。是半郡县，半分封制的汉朝。这是不是也印证了后面的“有些存世，有些转生”？正如某位哲人所说的：“不是胎生，不是卵生，而是转生。”宗法制最终变为了封建制的一部分，融入了封建制中，以另一种形式转生了，继续存在下去。而我们再来看看第二层含义，来看七龙王指代的人物本身。他们是礼乐宗法制度背后的拥护者，维护者，他们是不是得以幸存？秦始皇建立秦朝之后虽然把六国的国度给拆灭，把六国的王公贵族迁入咸阳，但这些旧秩序的维护者并没有受到肉体上的彻底消灭。甚至我们还知道，项羽直接就是楚国大将项燕的孙子，他直接投身到了对新生秩序的反抗，最终甚至得以成功。  
而最值得玩味地是“陆续”和“前两位降临者”的描述，它直接就向我们揭示了：这样的王朝更替，世代变换是时常发生的历史常态，这完全就是在向我们明示，提瓦特大陆上所发生的权力更替，其实质就是中国古代上的朝代更替，世代迭变。  
我们继续来看：  
>悬于提瓦特天空之上的“天空岛”，是包括“天理”在内的更高位阶神祇的居所，也是拥有强大愿望之人成神后的去处。  

我们都知道，天子天子，上天之子，天理天理，上天说的道理。天理是什么意思？是一个道理，是一个秩序。那么古代，打败了宗法制之后建立起的新的秩序是什么呢？是儒学封建制。它的人间化身代表是什么呢？没错。就是所谓“仁慈”的封建君主。天理本身象征着整个封建制度建立起来的秩序，而这个秩序的最高维护者，或者说，为了维持这个秩序而建立起来的，一个整个国家与制度的象征物，天子也代表着天理。那么天空岛，是包括“天理”在内更高位阶神祇的居所。如何理解这句话？天空岛，它在物理和设计上有意把这个国家中的普通人，也就是封建制度中的被统治对象和封建制度的统治者，建立者，维护者，隔绝开来，最终形成了一个阶层分明，但是稳定，高效的社会。  
>在提瓦特大陆的地底埋藏着被“天理”覆灭的古国“坎瑞亚”的遗迹。不同于与神同行的七国，坎瑞亚并不是由神祇统治，而是由人类创建和自治的国家。  

坎瑞亚代表着儒家经典中的大同社会，它是由“人类”而不是“神明”，也就是普通人，劳动百姓创造并治理的理想社会。但是它最后却由于某些不明的原因毁灭了。由劳动人民自己开创的大同社会最终被封建制度无情的碾压，最终死无葬身之地。或者换个说法，它有没有存在过呢？它是不是只是一个幻想呢？这不重要。重要的是，它在几千年的封建压迫统治下留下了一个遗迹，埋藏在提瓦特大陆中，也就是现世，埋藏在儒家礼乐经典中，留给后人们去索引，作为斗争的精神支柱，作为劳动人民对理想世界的美好愿望。但是这一丝幻想也最终破灭了。它转而化身成了又一柄利剑，被“天理”，被封建秩序维护者改写，变为又一把维护秩序，维护自身统治的大刀。  
>当一个人强大的愿望获得“天理”的注意，七神受“天理”指示，就会给予认可之人自己“神座”的部分力量，具象化为法器“神之眼”。“神之眼”给予使用者驱动某一元素之能；同时，此人也获得了登上天空岛成神的资格，称为“原神”。  

首先我们先来解释七神是什么东西。在七龙王时期，七龙王代表着七个宗法制的分封国家，但是封建制建立以后呢，“天理”也就是封建统治集团在各地委任了七神来统治提瓦特大陆。大家要注意这里的前后区别，原来的七龙王，是本来就统治着提瓦特大陆各地。而七神，则是被“天理”委任来统治提瓦特大陆的。“七神”的权力需要获得“天理”的许可。七神代表着封建制下，皇权在地方的代表。皇权三省六部，六部尚书，外加一位统领六部的丞相，正好为七位在皇宫位高权重的行政官僚，分封七神于各地，就是暗示着封建皇权通过这个封建制度的行政体系，牢牢掌握着从中央，到地方的各级权力，而七神则是封建皇权在地方代表。七神必须经过“天理”，也就是皇权的委任，才能具有权力。那我们回过头来看上一句话，大家还记得“也是拥有强大愿望之人成神后的去处”吗？当一个人强大的愿望获得“天理”的注意，七神受“天理”指示，就会给予认可之人自己“神座”的部分力量，具象化为法器“神之眼”。天空岛虽然把整个封建体系下的人们划分为了等级森严的三六九等，但是它并没有完全封死一切的上升通道，它最终还是留出了制度冗余，允许那些“拥有强大意愿的人使用“神之眼”，登上“天空岛”，变成原神。  
>“愚人众”也研发出了另一法器“邪眼”，由逝去魔神的遗骸残渣制成，可以通过投喂生命力来获得驱动元素之能。  

所谓“法器”实则就是封建体制下的权力上升通道，前面“神之眼”是一种，这里“邪眼”，也是一种。它是由逝去魔神的遗骸残渣制成，可以通过投喂生命力来获得驱动元素之能。这则是指不同于文官靠科举来谋求仕途的上升通道，指的是武将依赖杀敌掠地谋求权力。先来看投喂生命力：在过去生产力不发达的古代，因为军队作为国家暴力机器本身的特殊性，无论是军队直接与敌人作战，还是驻城，行军，维持秩序，乃至军队募集，维持军队编制，建立军队编制，都需要靠一条一条的人命来堆积。逝去魔神的遗骸残渣制成，寓意着军队的发家，发展，壮大，本身就建立在对过去王朝的讨伐和征战之上，甚至军队建制本身都是建立在过去王朝旧军队制度上的。而愚人众这个名字也饶有趣味，它隐含着自古以来文官体系以及文人们对武将的诋毁与打压。是统治集团内部不同利益体为了争夺话语权而进行的相互拉踩。  

那么综上所述，原神的世界观实际上是对中国古代的深刻暗喻。限于篇幅原因啊，我们这一期只论证了提瓦特大陆和中国古代背景相关性。那么至于到底提瓦特大陆如何和明朝扯上关系，原神如何是悼明之作，我们且听下回论说。  

① 从“七龙王—远古—权力更替”切入  
先强调“远古”二字 → 把叙事拉到历史维度  
追问：为什么是七位，而不是任意数量  
将“龙王”理解为血统合法性 + 天命政治  
把这一层作为“旧秩序”的抽象模型，而不是具体事件  

② 引出“降临者”作为断裂点  
强调“来自世界之外” → 非内部演化  
把“第一王座/第二王座”理解为制度性力量  
论证重点放在：  
不是继承  
而是剥夺并重新分配权力  

③ “古龙大权被夺走并分派”的制度含义  
把“夺权”解释为去血缘化  
把“分派给七执政”解释为权力制度化  
不去纠结个人，而是讲权力形态变化  

⑥ 转向“天空岛”的空间隐喻  
从“悬于天空”讲权力的不可触及性  
把空间高度与合法性等级挂钩  
不解释成具体建筑，而是象征权力结构顶端  

④ “幸存 / 转生”作为历史不彻底性的证据  
强调文本没有用“消灭”“终结”  
解释“转生”不是复辟，而是结构回潮  
用这一点引出：  
权力形式会被打败  
但社会结构会存续  

⑤ “陆续”“前两位降临者”的时间感  
抓住“陆续”这个副词  
论证这是在暗示多次循环  
把重点放在“历史常态”而非一次革命  
引出历史周期律，而不是具体朝代对照  

⑩ 坎瑞亚的核心特征如何论证  
抓住两个关键词：  
非神统治  
人类自治  
把它解释为：  
去天命  
去神权  
作为对“天理体系”的根本否定  

⑪ “被覆灭 / 遗迹 / 地底”的叙事方向  
强调空间位置：地底 vs 天空  
把“遗迹”理解为思想残留而非现实存在  
不去争论它是否真实存在过  
强调它作为精神参照物的功能  

⑦ “天理”作为秩序本身而非人格  
强调“理”而不是“神”  
把它解释为：  
合法性  
规则  
运行逻辑  
让“天理”成为一个抽象统治集团  

⑧ “人成神”这一设定的政治含义  
不从玄幻角度讲，而从阶层跃迁讲  
强调“获得资格”而非“自由成神”  
为后文“神之眼”埋伏笔  

⑫ 回到“神之眼”的机制层面  
把注意力从“力量”转向“获取条件”  
强调“被注意 / 被认可”  
说明这是一个筛选机制  

⑬ 七神在此处再次出现的意义  
提醒听众：七不是第一次出现  
说明这是同一套权力体系的延续  
把七神解释为地方权力节点  

⑭ “分一部分神座力量”的论证重点  
强调：不是完整权力  
是被允许使用的一部分  
引出：  
你不是统治者  
你是被吸纳者  

⑮ “原神”称号的制度化含义  
不从角色光环讲  
从“身份转变”讲  
把“原神”当作体制内成功者标签  

⑯ 转向“邪眼”作为对照组  
明确这是另一条路径  
不急着评价正邪  
先讲机制差异  

⑰ “投喂生命力”的现实指向  
把“生命”理解为社会成本  
把消耗当作结构性特征  
不落入残酷描写，而讲制度逻辑  

⑱ “魔神遗骸”的历史指向  
强调“遗骸”来自过去  
论证权力来源于旧秩序的毁灭  
指向暴力型上升路线  

⑲ “愚人众”命名的论证角度  
不从字面解释  
从话语权争夺解释  
强调这是体系内部的互相贬低  

⑳ 收束：两条上升通道的共性  
文官 / 武将看似不同  
实际都服务于同一秩序  
点出：  
没有真正跳出天空岛结构
