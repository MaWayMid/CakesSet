# 向往生路
马玮民 著  

今天早上，我起床，洗脸，刷牙，直视镜子里面自己的眼睛，它没有神。  
这样的日子已经不是一天两天。我哈了口气，脸皮没有动，眼角也没有动，镜子上起了雾。我用手把那层雾擦干净，还是那双眼，不过嘴唇是抿着，略微带点点微笑。  

这间明亮，温馨的房子是欠缺打理。纸巾，小票，饮料瓶，打包盒肆意地生长在茶几，餐桌，卧室，厨房，垃圾袋里，集中，积攒，等待统一处理。房子很大，至少对于一个人居住来说的确是这样的。主卧和一个小房间空着，小房间被当成了杂物间，但是还是摆了一张空床。  
房子的主人是谢致群，男，二十四，或二十五岁，本科毕业，工作类似库管，自由工作时间。  
他不睡主卧，睡小卧室。这间小卧室里摆上了一个书架，还有一张桌子。是他平时工作，学习，娱乐的场所。他十分享受在这里度过的时光。但是，这样平静的日子度过几年后，他也会时不时在专心致志地工作中望向窗外，窗帘紧闭的窗外。  

他也不知道为什么。他也想知道为什么。每次他都越看越久，眉头越皱越紧，眼神越来越迷茫。  

我起得越来越早。起得早不算什么坏事。有的时候，凌晨四五点钟的街头，我起床，空荡荡的马路上，只有环卫工人，泥头车，还有我，在一盏又一盏橙黄色路灯的照映下奔行。  

这一天早上，我起床，散完步，拿着早餐回到家，正吃着，我家的大门响起来了。  
阳台的门是开着的，时不时有微风吹进来，阳光也斜射到我的脸上，照到我的眼睛里，我看了看阳台上随风飘拂的衣物，起身——  
我伏在门口，透过猫眼，看到一个身材矮小，短发，脸色麦黄的少女，提着编织袋。
